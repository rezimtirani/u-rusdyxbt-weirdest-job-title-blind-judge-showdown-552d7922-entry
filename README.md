One job title, the weirdest one I could think of:

> Chief Officer of Checking If the Fridge Light Is On

`main.py` writes that single title to `/output/entry.txt` — plain UTF-8
text, one line, nothing else. It uses only the Python standard library
and never writes anything into the repository folder itself.
